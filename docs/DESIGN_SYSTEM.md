# Design System Standards

## Foundations
- Colors: Muted, premium scales (Vercel/Apple inspired).
- Typography: Inter.
- Radius: 0.5rem (md) standard.
- Elevation: Soft shadow variables (e.g. `--shadow-premium`).

## Accessibility
- Minimum 4.5:1 contrast.
- `aria-labels` on icon-only buttons.
- Keyboard navigability required.
